# Cortex web application

Next.js workspace for Today, Overview, Calendar, Tasks, Agent, Docs, Wiki, Recall, Activity, and Settings. Apple Dark is the default.

- [Quick start and features](../README.md)
- [Complete feature guide](../docs/FEATURES.md)
- [Private deployment](DEPLOY.md)
- [Calendar OAuth setup](CALENDAR.md)
- [Codex companion](../tooling/cortex-codex-bridge/README.md)
- [Integration API](API.md)

Run `npm ci`, `npm run dev` from this directory. The default vault is the bundled empty starter; use `VAULT_PATH` to explicitly select your own separate vault. Run `npm test` and `npm run build` to validate changes.
