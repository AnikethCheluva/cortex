# Vault Sources Rule

Read this file in any session that touches `Sources/`.

---

## The Rule

**`Sources/` is immutable raw data storage.** You read from it; you never write to it.

Only original, unmodified files belong here: PDFs, downloads, datasets. Nothing generated by Claude or the user — no notes, no summaries, no study guides.

**All generated output goes in the wiki layers:**

| Content type | Correct location |
|---|---|
| Course notes, study guides, problem sets | `Classes/` |
| Paper reading notes | `Research/Readings/` |
| Research working notes | `Research/Notes/` |
| Weekly research logs | `Research/Log/` |
| Daily notes | `Daily/` |
| Job applications, company research | `Personal/Career/` |

## Sources/ Subfolder Schema (per course)

```
Sources/[COURSE_CODE]/
├── textbook_chapters/   ← Raw PDF chapters
├── my_submissions/      ← Exams, homeworks you submitted
├── reference/           ← Syllabi, handouts, reference sheets
└── homework_solutions/  ← Solution PDFs
```

All four subfolders should exist for every active course. Create them when ingesting the first source for a new course.

## Enforcement

- If you accidentally create a generated file in `Sources/`: delete it immediately and recreate it in the correct folder.
- When ingesting new source material: place PDFs in `Sources/[COURSE]/[subfolder]/`, then generate wiki output outside `Sources/`.
- When a new course arrives: create all four subfolders before placing any files.
