# Welcome to Docs

This is a **persistent document** — a Google-Docs-style, long-form note. Unlike a
daily note, it isn't dated; it's a living document you keep editing.

Each doc is stored as a plain markdown **source** at `sources/notes/<slug>.md`, so
it's version-controlled like everything else and gets compiled into the wiki on
the next ingest.

Try it: open the **Docs** tab in the web app, edit this page, and watch it save
back to the repo. Then create your own with **New document**.

- Rich text editing (bold, headings, lists, quotes, code, tables)
- Write LaTeX inline: $e^{i\pi} + 1 = 0$
- Everything is just markdown underneath
