Welcome — this is a **hub** page, the kind you use to navigate a topic. This
example vault is fictional demo content shipped with the Cortex skeleton so the
app has something to render. Replace it with your own.

## How it's organized
Every page has exactly one **type tag** first (`concept`, `project`, `paper`,
`personal`, `hub`, …) which decides its folder in the web viewer, then topical
tags. See `wiki/wiki-schema.md` for the full rules. Daily notes live in
`sources/daily/`, the task board in `wiki/tasks/`, and this catalog is
`wiki/index.md`.
